# Challenge 04: Department salary total beside each employee

## Required result

Return `EmployeeID`, `FullName`, `DepartmentName`, `Salary`, and `DepartmentSalaryTotal` using `dbo.Employees` and `dbo.Departments`, with `DepartmentSalaryTotal` showing the total of `Salary` for rows that have the same `DepartmentID`.
Sort the final result by `DepartmentName` and `EmployeeID` in ascending order.

## Table(s)

- `dbo.Employees`
- `dbo.Departments`

## Columns to show

- `EmployeeID`
- `FullName`
- `DepartmentName`
- `Salary`
- `DepartmentSalaryTotal`

## Important

- Keep the source detail rows; the calculated value must appear beside each required row.
- Write your solution in `MySolution.sql` before checking `Solution.sql`.
