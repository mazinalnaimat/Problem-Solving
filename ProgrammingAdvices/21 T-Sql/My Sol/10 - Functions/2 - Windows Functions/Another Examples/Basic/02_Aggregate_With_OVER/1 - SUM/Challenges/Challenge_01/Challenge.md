# Challenge 1: SUM

## Required result

Return `DepartmentName`, `FullName`, `Salary`, and `SUM_SalaryInDepartment` using `dbo.Employees` and `dbo.Departments`, with `SUM_SalaryInDepartment` showing the total of `Salary` for rows that have the same `DepartmentID`.
Sort the final result by `DepartmentName` and `FullName` in ascending order.

## Table(s)

- `dbo.Employees`
- `dbo.Departments`

## Columns to show

- `DepartmentName`
- `FullName`
- `Salary`
- `SUM_SalaryInDepartment`

## Important

- Keep the source detail rows; the calculated value must appear beside each required row.
- Write your solution in `MySol.sql` before checking `Solution.sql`.
