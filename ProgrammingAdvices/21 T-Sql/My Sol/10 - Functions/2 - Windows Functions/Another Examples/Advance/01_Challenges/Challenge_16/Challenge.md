# Challenge 16: Manager Team Revenue Ranking

**Difficulty:** Hard  
**Database:** `RetailOperations3NFDB`

## Business scenario

Executives want a monthly ranking of managers based on revenue generated by all sales employees below them in the reporting hierarchy.

## Task

Use a recursive employee hierarchy, aggregate descendant sales revenue by manager and month, then rank managers within each month.

## Input tables

- `dbo.Employees`
- `dbo.SalesOrders`
- `dbo.OrderItems`

## Output columns

Return the columns in this exact order:

1. `MonthStart`
2. `ManagerNumber`
3. `ManagerName`
4. `TeamRevenue`
5. `ManagerRank`

## Business rules and constraints

- Exclude cancelled orders.
- A manager's own orders count if the manager is also in the descendant chain.
- Use a recursive CTE and `RANK`.

## Required SQL techniques

- Use at least one Common Table Expression (`WITH ... AS`).
- Use one or more SQL Server window functions.
- Do not solve the challenge with procedural loops or cursors.
- Your result must be deterministic when values tie.

## Required ordering

Order the final result by:

```sql
ORDER BY MonthStart, ManagerRank, ManagerNumber
```
