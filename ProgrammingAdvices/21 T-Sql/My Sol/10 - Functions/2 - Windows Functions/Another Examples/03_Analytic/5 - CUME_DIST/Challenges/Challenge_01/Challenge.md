# Challenge 1: CUME_DIST challenge 1: temperature inside each machine

## Task

Calculate the cumulative distribution of temperature inside each machine while keeping every detail row.

## Requirements

- Use `CUME_DIST()`.
- Partition by `MachineCode`.
- Order by `TemperatureC`.
