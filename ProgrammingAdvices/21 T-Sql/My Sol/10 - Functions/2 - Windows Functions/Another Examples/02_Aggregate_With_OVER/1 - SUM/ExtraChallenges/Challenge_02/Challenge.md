# Challenge 02: Total sales for every region

## Required result

Return `Region` and `RegionTotal` from `dbo.SalesOrders`, with one row for each unique combination of `Region` and `RegionTotal` showing the total of `Amount` for that group.
Sort the final result by `Region` in ascending order.

## Table(s)

- `dbo.SalesOrders`

## Columns to show

- `Region`
- `RegionTotal`

## Important

- Return one row for each required group, not every source detail row.
- Write your solution in `MySolution.sql` before checking `Solution.sql`.
