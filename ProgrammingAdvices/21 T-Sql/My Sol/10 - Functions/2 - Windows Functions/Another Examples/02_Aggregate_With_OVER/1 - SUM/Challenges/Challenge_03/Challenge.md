# Challenge 3: SUM

## Required result

Return `ClassName`, `StudentName`, `Score`, and `SUM_ScoreInClass` from `dbo.StudentScores`, with `SUM_ScoreInClass` showing the total of `Score` for rows that have the same `ClassName`.
Sort the final result by `ClassName` and `StudentName` in ascending order.

## Table(s)

- `dbo.StudentScores`

## Columns to show

- `ClassName`
- `StudentName`
- `Score`
- `SUM_ScoreInClass`

## Important

- Keep the source detail rows; the calculated value must appear beside each required row.
- Write your solution in `MySol.sql` before checking `Solution.sql`.
